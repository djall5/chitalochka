# Прототип персонажа

Это черновой образец героя для будущей игры «Оживи пустыню», не окончательная внешность ученика.

- `reference-sheet.png` — исходный лист, присланный пользователем.
- `front.png`, `back.png`, `side.png`, `three-quarter.png` — четыре отдельных ракурса на прозрачном холсте 1024 × 1536. Они подготовлены генератором изображений по исходному листу; некоторые детали могли измениться.

При персонализации по фотографии ученика сохранять единый стиль, одежду, масштаб и положение ступней во всех четырёх ракурсах. Новые варианты сохранять отдельно; исходный лист и этот прототип не заменять без явного решения пользователя.
